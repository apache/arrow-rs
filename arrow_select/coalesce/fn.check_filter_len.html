fn check_filter_len(
    filter: &FilterPredicate,
    source_len: usize,
) -> Result<(), ArrowError>
Expand description

Return an error if filter is longer than the source array it is applied to.

A FilterPredicate yields positions less than its length, so once this check passes, the filter is guaranteed to produce valid indices less than source_len.
