pub(crate) fn child_values_ptr_eq(left: &ArrayRef, right: &ArrayRef) -> bool
Expand description

Returns true if two child value arrays have the same layout and backing buffers.

This first checks whether the [ArrayRef]s point to the same allocation, then uses direct buffer comparisons for byte arrays and [arrow_data::ArrayData::ptr_eq] for other types.

This checks storage identity, not logical equality. Arrays with equal values in different buffers return false. Arrays with no allocated storage, such as two empty primitive arrays built from empty Vecs or two [arrow_array::NullArray]s of the same length, return true.
