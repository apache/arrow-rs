Module sql_info 

Source
Expand description

Helpers for building responses to CommandGetSqlInfo metadata requests.

  • SqlInfoDataBuilder - a builder for collecting sql infos and building a conformant RecordBatch with sql info server metadata.
  • SqlInfoData - a helper type wrapping a RecordBatch used for storing sql info server metadata.
  • GetSqlInfoBuilder - a builder for constructing CommandGetSqlInfo responses.
