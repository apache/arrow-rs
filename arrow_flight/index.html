Expand description

A native Rust implementation of Apache Arrow Flight for exchanging Arrow data between processes.

Please see the arrow-flight crates.io page for feature flags and more information.

§Overview

This crate contains:

  1. Low level prost generated structs for Flight gRPC protobuf messages, such as FlightData, FlightInfo, Location and Ticket.

  2. Low level [tonic] generated flight_service_client and flight_service_server.

  3. Support for Flight SQL in sql. Requires the flight-sql feature of this crate to be activated.

§Platform Support

Only little-endian platforms are officially supported and tested in CI. Big-endian platforms are not tested in CI and may not work correctly. Fixes for big-endian platforms are welcome and handled on a best-effort basis, but compatibility is not guaranteed.
