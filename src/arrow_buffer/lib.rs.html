5//! Low-level buffer abstractions for [Apache Arrow Rust](https://docs.rs/arrow)
6//!
7//! # Byte Storage abstractions
8//! - [`MutableBuffer`]: Raw memory buffer that can be mutated and grown
9//! - [`Buffer`]: Immutable buffer that is shared across threads
10//!
11//! # Typed Abstractions
12//!
13//! There are also several wrappers over [`Buffer`] with methods for
14//! easier manipulation:
15//!
16//! - [`BooleanBuffer`][]: Bitmasks (buffer of packed bits)
17//! - [`NullBuffer`][]: Arrow null (validity) bitmaps ([`BooleanBuffer`] with extra utilities)
18//! - [`ScalarBuffer<T>`][]: Typed buffer for primitive types (e.g., `i32`, `f64`)
19//! - [`OffsetBuffer<O>`][]: Offsets used in variable-length types (e.g., strings, lists)
20//! - [`RunEndBuffer<E>`][]: Run-ends used in run-encoded data
21//!
22//! # Platform Support
23//!
24//! Only little-endian platforms are officially supported and tested in CI.
25//! Big-endian platforms are not tested in CI and may not work correctly.
26//! Fixes for big-endian platforms are welcome and handled on a best-effort basis,
27//! but compatibility is not guaranteed.
