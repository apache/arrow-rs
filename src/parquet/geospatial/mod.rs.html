5//! This module provides functionality for working with geospatial data in Parquet file as defined in the [spec][parquet-geo-spec].
6//!
7//! * [`GeospatialStatistics`]: describes the geospatial statistics for a Parquet column.
8//! * [`BoundingBox`]: describes the bounding box values for a geospatial column.
9//!
10//! [`GeospatialStatistics`] describes the geospatial statistics for a Parquet column.
11//! * bbox: the [`BoundingBox`] for the geospatial data
12//! * geospatial_types: the geospatial types for the geospatial data as specified in [specification][geo-types].
13//!
14//! Geospatial bounding box describes the spatial extent of the geospatial data within a Parquet row group.
15//! * xmin, xmax: the minimum and maximum longitude values
16//! * ymin, ymax: the minimum and maximum latitude values
17//! * zmin, zmax: (optional) the minimum and maximum elevation values
18//! * mmin, mmax: (optional) the minimum and maximum linear reference values
19//!
20//! In 2D representation, where x are points:
21//! ```text
22//!  ymax +-----------------------+
23//!       |               x       |
24//!       |      x                |
25//!       |              x        |
26//!       |      x                |
27//!  ymin +-----------------------+
28//!       xmin                    xmax
29//! ```
30//!
31//! [`GeospatialStatistics`]: crate::geospatial::statistics::GeospatialStatistics
32//! [`BoundingBox`]: crate::geospatial::bounding_box::BoundingBox
33//! [parquet-geo-spec]: https://github.com/apache/parquet-format/blob/master/Geospatial.md
34//! [geo-types]: https://github.com/apache/parquet-format/blob/master/Geospatial.md#geospatial-types
35
