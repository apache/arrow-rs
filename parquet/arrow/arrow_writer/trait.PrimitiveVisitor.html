Expand description

Receives the values ArrowWriter stores for an Arrow array in an INT32 (T = i32) or INT64 (T = i64) column, which are also the values hashed into the column’s bloom filter

visit_i32 and visit_i64 hold the conversion from each Arrow type, and call Self::slice when the Arrow values are stored as they are, or Self::map when each value is converted. This lets the writer borrow the Arrow buffer when no conversion is needed.
