Module column_chunk 

Source
Expand description

Sparse storage keyed by row-group and column coordinates.

Builders use ColumnChunkMap for arbitrary insertion and replacement. Finished indexes use ColumnChunkEntries, a sorted boxed slice containing only populated entries. This reduces retained memory at the cost of binary-search vs hash lookups.
