# `arrow-bitutils`

Word-at-a-time bit and byte manipulation primitives for [Apache Arrow], shared by `arrow-buffer`, `parquet`, and the compute kernels, so that each is implemented, tested, and tuned once.

See the [main repository README] and the [API documentation] for more details.

## Security

See the [Security Policy] for information on the security model and how to report vulnerabilities.
