Expand description

Builds the array from the output of collect_overflowing, or returns None if a valid row overflowed.

A null slot can hold any value, such as the 0 that builders write, which overflows unsigned 0 - 1. So when a slot overflowed, this recomputes the overflow of every row with overflowed and masks it with the validity bits, instead of making the caller rerun the whole batch.
